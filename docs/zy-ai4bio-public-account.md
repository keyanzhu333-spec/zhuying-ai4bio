# ZY-AI4Bio：把结构生物学与药物发现流程连接起来

研究一个蛋白和小分子的相互作用，常常要先找结构、准备配体，再做对接、筛选、相互作用分析，必要时还要运行分子动力学。每一步都有工具，但文件、参数和结果很容易散落在不同软件中。

ZY-AI4Bio 是一套可由 Codex 调用的生命科学技能。研究人员描述任务后，它可以选择相应工具，组织计算步骤，并保存输入、参数和结果，方便后续检查与复现。

## 从结构预测到候选筛选

针对蛋白与小分子，ZY-AI4Bio 可调用 **DiffDock** 探索未知结合口袋，使用 **GNINA** 对接和复评分，并通过 **UniDock-Pro** 对准备好的小分子库进行批量虚拟筛选。排名靠前的候选物，还可以交给 **PLIP 和 PyMOL** 分析关键残基、相互作用及结合构象。

研究对象不局限于小分子。**LightDock** 可用于蛋白-蛋白、蛋白-DNA/RNA 对接；有实验约束时可使用 **HADDOCK3** 精修蛋白-核酸复合物；从序列出发时，可用 **Chai-1** 预测复合物结构。系统还支持蛋白互作候选筛选，以及“一个小分子对多个蛋白靶点”的反向虚拟筛选。

## 对接之后，还能继续分析

ZY-AI4Bio 的 **GROMACS** 工作流覆盖单蛋白、蛋白-蛋白、蛋白-核酸、蛋白-小分子和蛋白-金属五类体系。模拟后可整理 RMSD、RMSF、氢键、界面接触等轨迹指标并绘图；在体系与参数经过检查后，也可开展 MM/PBSA 分析。分子动力学项目按 `inputs/`、`simulation/`、`analysis/` 组织，便于回看每一步。

除此之外，它还可衔接抗体结构预测、序列与结构查看、PubChem 和 ChEMBL 等数据库查询，以及 PubMed、PMC、bioRxiv 文献检索。数据库与查看器技能需在 Codex 中另行安装。

ZY-AI4Bio 希望帮助研究人员从一个结构问题出发，逐步得到可检查的候选构象、筛选排名和分析结果。**计算结果用于提出和筛选假设，最终仍需要实验验证。**
