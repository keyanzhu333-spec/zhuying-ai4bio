# ZY-AI4Bio 更新记录：2026-10-20

本次更新重点完善技能的跨电脑部署和实际执行流程，将可复用脚本、模拟参数模板、环境检查与安装说明纳入仓库，并提供已安装用户的备份更新方式。

## 新增与完善

- **分子动力学**：加入 EM、NVT、NPT、Production 四阶段 MDP 参数模板、GROMACS 环境检测和分阶段执行脚本；支持 CPU/GPU 选择、checkpoint 续跑、输入校验及生产阶段显式确认。
- **复合物结构预测与对接**：加入 Chai-1、HADDOCK3 通用启动脚本；完善 LightDock、PPI 筛选、UniDock 和反向筛选的工具路径解析与依赖检查。
- **相互作用分析和绘图**：完善 GNINA、PLIP、PyMOL 环境配置与调用；GNINA 整体图默认不显示残基标签、原子/残基编号、图例及引线，局部互作图保留残基标注、防碰撞布局和元素着色。PNG 与 PyMOL 会话使用一致规则。
- **跨电脑部署**：增加统一环境检查、工具路径配置样例、外部资源清单样例和逐技能依赖安装说明。
- **本机技能升级**：安装器新增 `--update`，自动备份旧版，保留运行时、虚拟环境、模型和私有配置，并记录安装来源的 Git 提交号。更新失败时恢复原技能。
- **分享与隐私**：发布内容不包含本机运行时、模型权重、研究轨迹、私人目录和密钥；提供源码发布扫描，环境报告默认隐藏绝对路径。README 中主动公开的联系方式保留。

## 验证与使用范围

已完成隔离 Python 环境中的离线回归检查，以及 GROMACS 小水盒四阶段短测试和 checkpoint 续跑。短测试验证执行流程，不代表研究体系的采样或收敛已得到验证。

Linux/Windows 自动测试配置以模板形式提供，尚需有工作流权限的账号启用。科学软件、GPU 驱动、API 凭据、模型权重及大型筛选库仍需在使用者电脑上按说明准备；资源清单样例不是完整数据库下载器。

## 已安装用户更新

在已克隆的仓库目录运行：

```bash
git pull --ff-only
python3 scripts/install_skills.py --update --dry-run
python3 scripts/install_skills.py --update
```

旧技能保存在活动技能目录旁的 `skill-backups/` 中；脚本会打印备份位置。下一轮 Codex 对话即可使用新版。

项目地址：[zhuying-ai4bio](https://github.com/keyanzhu333-spec/zhuying-ai4bio)。详细安装与验证方法见 [跨电脑安装说明](../portable-installation.md)。
